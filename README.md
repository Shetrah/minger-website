# MINGER Website

Updated Vite + React website for MINGER.

## New improvements included

- English / Chinese language toggle
- MINGER logo used in the header and favicon
- Home page shower-gel human illustration
- Embedded brand videos for laundry, dishwashing, and shower-gel storytelling
- More detailed About Us page
- Smoother page transition effect between routes
- Refined styling for a more lively and attractive presentation

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
